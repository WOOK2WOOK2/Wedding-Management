웹 배포 및 파일 공유 가이드

이 프로그램은 단일 HTML 파일로 구성되어 있습니다. 소스 파일을 직접 다운로드하거나 무료 웹 서비스를 사용하여 온라인 공유 링크를 만들 수 있습니다.

1. 파일 형태로 내 컴퓨터에 저장하기

현재 수정 및 완성된 시스템 전체 코드 그대로 .html 파일로 다운로드합니다.

2. 나만의 무료 인터넷 링크(URL) 만들기

  1. 위 버튼을 눌러 HTML 파일을 먼저 다운로드받습니다.
  2. 무료 호스팅 서비스 Netlify Drop 페이지에 접속합니다.
  3. 다운로드 받은 HTML 파일을 화면에 드래그 앤 드롭합니다.
  4. 즉시 접속 가능한 전용 웹 URL이 바로 생성됩니다!
